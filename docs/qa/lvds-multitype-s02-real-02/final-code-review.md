# S02-REAL-02 代码只读审查

审查范围：本轮 `ExcitationFrame` 时间语义、AB CSV v2、当前 AB UI 无时间分支，以及 `backend_s02_real02_tests.rs` 与其使用的生产历史/保存入口。此次审查没有修改生产或测试源码，没有运行 Cargo，没有连接设备。以下覆盖描述指测试代码包含的检查，不表示本次审查执行了这些检查；主代理的最终运行、独立文件读回和 Release 结果另行确认。

**结论：在已审查范围内未发现阻断交付的生产缺陷。** 以下兼容条件和证据边界需要在最终验收报告保留。

## 需要明确的兼容条件与限制

1. **CSV v2 是保留前列的扩展，旧读取器仍可能需要适配。** 原 22 列名称/顺序保持，有正间隔的原 400 行黄金文件与 v2 对应行前 22 列完全一致。v2 总列数为 25，追加 `interval_us,points,waveform_status`；无时间状态行的 `sample_time_us` 是空字符串。严格要求 22 列、解构固定 22 项，或无条件把时间转成整数的旧读取器会失败。读取器应按列名读取并识别空时间及状态，不应把空值补为设备包时间或零。旧 `tools/qa/lvds_s02_real_reference.py` 的全字段读回仍严格要求旧 22 列，不能直接用于新 v2 CSV；本轮 `lvds_s02_real02_reference.py` 已实现 25 列独立核对，实际生产文件结果以运行报告为准。旧验收输出和证据不应改写。

2. **Rust 正式专项和独立 CSV 读回共同组成完整验收。** 新后端专项逐字段比较全部解码 AB、AA/LPD、两个 RAW，并检查 CSV 写入状态、行数和完整历史导出；CSV 的全部 25 列内容及精确 EOF，由独立 Python `verify` 补齐。`production-summary.json` 中的 `status=PASS` 不能单独作为所有 CSV 已完成独立逐字段读回的证据。最终全存储结论应等待 direct、PCAP 历史、RAW 历史三个 AB CSV 的独立报告。

3. **AB 历史定位仍是有界后台前缀重扫，最坏 O(N)。** 新专项对全部 175 帧执行选择并覆盖首尾反向选择，能够证明本输入的内容和导航正确；它没有证明任意大文件的常数时间随机定位。原生 Windows GUI 和真实硬件持续采集也不属于此后端专项，测试中已明确标记未执行。

## 核心与保存审查

- `has_sample_timing()` 仅判断 `interval_us > 0`，不从工作模式、频率或全零波形推断有效性。间隔为零时 `sample_time_us()` 在任何槽位返回 `None`；原始设备包时间、100 个 mV、CRC 和全部状态字段保留。
- 解码器没有提前接受状态帧；微秒、points、模式、设定值、状态、保留区和样本范围检查仍全部执行。采样窗下溢拒收只针对正间隔。CRC 继续保留且不设生产校验门禁。
- CSV 对无时间帧仍保存 100 行，时间为空并写 `NO_SAMPLE_TIME`；有时间帧使用 `TIMED_SAMPLES`。`wave_V` 始终只是原始 `wave_mV/1000` 的数值换算，状态区分无时间槽位和有时间数据，不使用 DC 设定值伪造采样值。
- 正间隔的非法时间仍报 `InvalidSampleTime`，当前窗口先在内存中完成格式化才写出；失败沿用关闭/禁止重试机制，已确认行数不会增加。路径使用独占创建，旧输出不会被截断。
- 当前 UI 对无时间帧不调用波形图绘制，清除游标、将渲染点数设为零并显示无有效激励波形/逐点时间不可用；配置与原始状态仍可见。没有从 DC 设定值生成水平实测线。

## 离线入口与历史覆盖审查

- 专项拒绝 Mock 构建，要求显式输入、独立 schema 2 manifest 和新输出目录。运行前后核对原 PCAP SHA256，输出目录及文件独占创建。
- 测试的 `Controller::new` 默认 `rs422/lvds/lvds_udp=None`。专项只创建文件 writer、文件回放和历史 reader；没有调用串口连接、UDP 绑定、RS422/星务发送。手动设置的 `lvds_connected=true` 用于回放状态，不创建传输对象。科学保存初始化也只创建存储 writer。
- GUI 构造当前仅提交 `RefreshPorts`，不会自动提交连接或星务启动。`--audit-pcap` 在创建 GUI/后端之前进入只读文件审计并返回。
- 首帧前建立 AA CSV/LPD、AB CSV 与 RAW writer。生产 `PcapReplay` 正常时间轴回放，没有修改 `started` 来加速；比较独立纳秒捕获跨度和运行时长。
- AA 按每组 1000 帧分成 4 个窗口，窗口均小于生产 60 秒限制。每组最大 100000 个点/通道，低于 120100 点上限；逐点核对两通道数值、设备时间及来源记录 ID，并核对总计 348900 点/通道。没有把首个显示窗口当成全文件。
- PCAP 和 RAW 历史逐个选择全部 175 个 AB，比较全部字段、原始 CRC、100 个值及可空时间；随后通过生产后台入口全文件导出 AB CSV。LPD 明确只含 AA，AB 数量为零。
- 主回放始终不消费显示队列并要求显示丢弃实际发生，同时检查业务保存零丢失和正常关闭；显示背压与保存路径被独立覆盖。RAW 逐个核对全部 3873 个 UDP，其中来源接纳统计是 3839，额外 34 个来源不符报文保留在 RAW，统计口径未混用。
