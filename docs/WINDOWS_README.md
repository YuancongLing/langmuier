# Langmuier Probe Ground Control

Windows x64 非 Mock 版。当前交付目录为 `target/delivery/lvds-multitype-s02-real-02-20261121/`，运行其中的 `LangmuierProbeGroundControl.exe`，窗口和页眉显示 `S02-REAL-02 (20261121)`。程序默认使用真实通信后端，启动时不会生成模拟数据、连接设备或发送控制指令。真实抓包的软件与文件验收结果见 `docs/LVDS_MULTITYPE_S02_REAL_202611212141_ACCEPTANCE.md`；原生 Windows GUI 操作尚未验收。

## 查看已有数据

点击图表上方常驻的“打开历史”（窄窗口显示“历史”），浏览或填写完整文件路径后点击“打开”。支持：

- `.lvdsraw`：保留 UDP 原始字节、端点、时间与记录索引的归档。
- `.lpd`：当前 LPD v3 科学数据文件；不支持旧版 v2。
- `.pcapng`：原始网络抓包。

主界面显示“历史模式”，可播放、暂停、回到起点、拖动进度条定位及退出。直接点击“科学波形 AA”或“激励波形 AB”切换视图。AA 科学图表支持双通道叠加 / 分屏（在“显示”菜单选择）、左键拖动平移、滚轮缩放、跟随、冻结和重置。AA 横轴为设备时间，采样间隔为 500 微秒；纵轴和游标以电压 V 显示，默认两位小数。AA 历史窗口可指定最多 60 秒的加载区间。AB 的时间和电压换算见下方“激励波形 AB”。CSV 为保存/导出格式，不能在此作为历史文件打开。

AA 两路科学波形统一采用 ADS8691 当前 ±5.12V 量程：`voltage_v = code10 × 0.01 - 5.12`，显示范围为 -5.12V 至 +5.11V。纵轴按可见数据自动拟合，手动缩放和平移可保留，点击“重置视图”恢复自动拟合。独立归一化的纵轴为归一化幅值，图例和游标仍给出实际电压。

“历史与原始数据”窗口提供文件信息、帧序号、异常列表和 CSV 导出。电压换算仅影响显示；LPD v3 仍保存原始 code10，普通 CSV 保持 11 列，保存原始 code10、重建 ADC 及采样时间。导出读取文件中的完整科学样本，不使用图表抽稀点。

## 原始 UDP 录制

实时接收需先手动配置并开始 UDP 监听。本地地址必须已配置在 Windows 网卡上，软件不会自动修改系统地址。

“开始原始录制 / 停止原始录制”独立于科学数据的“开始保存 / 停止保存”。原始录制保存当前监听 Socket 实际收到的全部 UDP Payload，包括来源不匹配、重复和解码失败的数据。在 PCAPNG 历史模式下，原始录制导出整个抓包中的 UDP 记录。

自动输出位于工作目录 `data/`，每次生成新文件名；设置窗口可指定新路径。同名文件拒绝覆盖。原始录制分别显示收到、入队、写入、丢失和关闭状态；写入错误或数据丢失会明确提示。应用归档无法证明数据在抵达 Socket 前没有丢失。

正常停止或退出时排空并关闭归档。异常中断或写入失败的文件保留已有记录，重开时显示不完整状态。

## LVDS 三类型接收

按最新协议接收固定 269B 的 AA 科学、AB 激励和 AC 星务帧。中央工具栏选择“科学波形 AA”或“激励波形 AB”。AB 已支持解码、绘图和独立 CSV；AC 保留完整原始数据并显示“待解码”。在“更多 → 接收详情”或历史模式“数据 → 接收详情”查看类型统计。未知类型单独计数，原始录制同样保留。

UDP 外层 u32 序号覆盖整个公共帧接收流，AA 内层 seq8 独立保存。辅助包可以任意位置到达，缺少 AB 或 AC 不影响 AA。普通 CSV 和 LPD v3 仍只包含 AA。三类 CRC 字节均原样保留，生产接收不验证 CRC；**科学数据未经 CRC 完整性验证**。本轮 `202611212141.pcapng` 生产回放得到 AA 3489、AB 175、AC 175；全部 3873 UDP 原始归档和科学/激励文件均已独立全量读回。真实网卡连续接收与原生 GUI 操作尚未验收。

## 激励波形 AB

选择“激励波形 AB”后，逐帧显示具有有效采样时间的 100 点波形。电压由原始 mV 除以 1000 得到 V；设备时间戳对应最后一个点，前面各点按包内采样间隔倒推。相邻帧可能重叠，界面逐帧查看，不拼接为连续曲线。

工具栏支持跟随最新、冻结、重置，图内左键拖动平移、滚轮缩放及鼠标点值。进入手动查看后保留当前帧，点击“跟随最新”恢复更新。“AB 详情”显示工作模式、实际 Hz、设定值、原始 0/1 状态、PA0 与最近科学序号、设备/接收时间及来源。采样间隔为 0 时，显示“当前无有效激励波形”和“无可用逐点采样时间”，保留模式、PA0 与 100 个原始槽位，不绘制占位零值。DC 电压以三位小数 V 显示为设定值，不作为实测曲线。

“AB CSV”菜单在 AA/AB 两个视图均可直接找到，可设置新文件路径并开始/停止保存；留空时自动写入工作目录 `data/`。保存独立于当前 AA/AB 视图，每个接纳 AB 包写入 100 行，保留原始 mV、计算 V、时间、来源与 `CRC_NOT_CHECKED`。要保存离线回放的第一帧，可先停止旧来源，再开始 AB CSV，最后启动 PCAP 回放；回放 EOF 或停止时关闭文件。AA 的“开始保存”仍单独控制 AA 文件。

打开 `.pcapng` / `.lvdsraw` 历史后切换到 AB，在“AB 详情”选择上一帧、下一帧或帧号，在“AB CSV”导出整份历史 AB 数据。索引和按需读取在后台进行；异常列表显示原始记录 ID 和失败原因。LPD v3 只含 AA，不含 AB。

AB CSV v2 保留原 22 列并追加 `interval_us`、`points`、`waveform_status`。无逐点时间的帧仍保留全部 100 行，`sample_time_us` 为空、状态为 `NO_SAMPLE_TIME`，零值只表示原始槽位。固定 22 列或要求时间必为整数的旧读取器需要适配，详见 `docs/AB_EXCITATION_CSV_V2.md`。

## 异常帧分析

“尝试恢复异常帧”默认关闭。启用后，对实际输入受控尝试 1bit / 4bit 位对齐恢复，保留原始字节及独立审计记录。质量筛选可显示原生帧、原生加已确认恢复，或明确标记的诊断候选。

恢复器只使用同一报文中实际存在的位，不借用相邻报文、不补造缺失尾位。诊断候选不等于已确认恢复。恢复及候选数据不会进入普通 LPD v3 / 11 列 CSV；主动包含这些数据的历史导出使用独立版本与质量、来源字段。

## 科学数据保存

实时或 PCAP 回放可选择 `LPD`、`CSV` 或 `LPD + CSV`。如需从 PCAP 的第一帧开始保存，使用“离线回放 PCAP”，预先勾选“回放时保存科学数据”，再开始回放。运行中点击“开始保存”仅保存此后的科学帧。

真实 RS422 串口、遥测和控制命令均由用户手动操作。文件回放与历史查看无需连接硬件。

## RS422 星务模拟

在左侧 RS422 控制区选择“星务模拟”。先明确选择并连接串口，再选择要发送的时间、姿态轨道、GNSS 广播，设置各自周期后点击“启动自动广播”；也可逐类单次发送。启动软件或重新连接串口都不会自动开启广播。点击“停止全部广播”取消尚未开始的周期帧；已经开始发送的完整帧会完成。

三个 GNSS 预设均为 SYNTHETIC 静止测试点，使用同一经纬高生成 WGS-84 ECEF 坐标，速度明确为零；点位切换是独立位置编码测试，不是连续卫星轨道。姿态、轨道和磁场同样是合成测试参数。界面预览不计入实际发送；发送数与最后帧来自串口写入成功记录，代表本地写入，不代表探针执行确认。

各周期可设 100–60000ms，默认1000ms是模拟策略。自动广播期间保留小于20秒的遥测轮询，默认5秒；广播无应答是正常协议行为。串口断开会停止全部广播，重新连接后须再次手动启动。使用真实串口时，这项功能会实际向设备发送数据，与科学数据 `--mock` 不同。

时间使用系统 UTC，转换为 2018-01-01 00:00:00 UTC 起累计秒，非整秒时间向下量化到25微秒。当前静态闰秒基准为2018年至2026年无新增闰秒，GPS–UTC为18秒；未来发生闰秒时须更新软件中的基准，系统POSIX时钟不能单独表达插入秒。应用记录发送调用时刻，真实线时序仍需硬件联调确认。
