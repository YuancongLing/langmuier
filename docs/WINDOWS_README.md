# Langmuier Probe Ground Control

Windows x64 正式版。运行 `LangmuierProbeGroundControl.exe`。程序默认使用真实通信后端，启动时不会生成模拟数据、连接设备或发送控制指令。

## 查看已有数据

点击中央操作区的“打开历史数据”（窄窗口显示“历史”），浏览或填写完整文件路径后点击“打开”。支持：

- `.lvdsraw`：保留 UDP 原始字节、端点、时间与记录索引的归档。
- `.lpd`：当前 LPD v3 科学数据文件；不支持旧版 v2。
- `.pcapng`：原始网络抓包。

主界面显示“历史模式”，可播放、暂停、回到起点、拖动进度条定位及退出。图表支持双通道叠加 / 分屏、左键拖动平移、滚轮缩放、跟随、冻结和重置。横轴为设备时间，采样间隔为 500 微秒；纵轴和游标以电压 V 显示，默认两位小数。历史窗口可指定最多 60 秒的加载区间。

两路波形统一采用 ADS8691 当前 ±5.12V 量程：`voltage_v = code10 × 0.01 - 5.12`，显示范围为 -5.12V 至 +5.11V。纵轴按可见数据自动拟合，手动缩放和平移可保留，点击“重置视图”恢复自动拟合。独立归一化的纵轴为归一化幅值，图例和游标仍给出实际电压。

“历史与原始数据”窗口提供文件信息、帧序号、异常列表和 CSV 导出。电压换算仅影响显示；LPD v3 仍保存原始 code10，普通 CSV 保持 11 列，保存原始 code10、重建 ADC 及采样时间。导出读取文件中的完整科学样本，不使用图表抽稀点。

## 原始 UDP 录制

实时接收需先手动配置并开始 UDP 监听。本地地址必须已配置在 Windows 网卡上，软件不会自动修改系统地址。

“开始原始录制 / 停止原始录制”独立于科学数据的“开始保存 / 停止保存”。原始录制保存当前监听 Socket 实际收到的全部 UDP Payload，包括来源不匹配、重复和解码失败的数据。在 PCAPNG 历史模式下，原始录制导出整个抓包中的 UDP 记录。

自动输出位于工作目录 `data/`，每次生成新文件名；设置窗口可指定新路径。同名文件拒绝覆盖。原始录制分别显示收到、入队、写入、丢失和关闭状态；写入错误或数据丢失会明确提示。应用归档无法证明数据在抵达 Socket 前没有丢失。

正常停止或退出时排空并关闭归档。异常中断或写入失败的文件保留已有记录，重开时显示不完整状态。

## 异常帧分析

“尝试恢复异常帧”默认关闭。启用后，对实际输入受控尝试 1bit / 4bit 位对齐恢复，保留原始字节及独立审计记录。质量筛选可显示原生帧、原生加已确认恢复，或明确标记的诊断候选。

恢复器只使用同一报文中实际存在的位，不借用相邻报文、不补造缺失尾位。诊断候选不等于已确认恢复。恢复及候选数据不会进入普通 LPD v3 / 11 列 CSV；主动包含这些数据的历史导出使用独立版本与质量、来源字段。

## 科学数据保存

实时或 PCAP 回放可选择 `LPD`、`CSV` 或 `LPD + CSV`。如需从 PCAP 的第一帧开始保存，使用“离线回放 PCAP”，预先勾选“回放时保存科学数据”，再开始回放。运行中点击“开始保存”仅保存此后的科学帧。

真实 RS422 串口、遥测和控制命令均由用户手动操作。文件回放与历史查看无需连接硬件。

本包包含当前源码重新构建的非 Mock、MSVC x64 静态 CRT 程序。完整格式、验证范围与硬件验收限制见源码仓库 `docs/LVDS_RAW_CAPTURE_RECOVERY_HISTORY_QA.md`。
