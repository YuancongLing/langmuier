# 等离子体探针载荷数据格式及编排要求（2026-07-24）

> 来源：`数据格式及编排要求-等离子体探针-20260724（公开）.docx`。
> 本文为便于软件实现和审查而转写的 Markdown；269B 布局以用户最终确认表为准。
> 2026-10-19 更新：CRC 算法按厂家 C，覆盖范围按新版表格“有效数据”的工作解释实施强制校验；范围仍待厂家实参确认。

## 接口与节奏

- 接口：LVDS；1 位时钟、1 位数据、1 位门控。
- 每 50 ms 一帧，即每秒 20 帧。
- CLK：11.11 MHz、占空比 45%–55%、仅在传输期间有效。
- FLAG：低电平有效，代表帧有效/允许发送。
- DAT：FLAG 下降后发送，FLAG 保持低电平直至一帧结束。
- 多字节字段高字节先输出；字节内高位先输出。

## 科学数据帧

用户最终确认的 LVDS 原始帧固定为 **269 字节**，末尾校验码为 **2 字节 CRC16（高字节在前）**。UDP 外层 `frame_len = 0x0000010D`，单分片时为 24B 头加 269B 负载。此前异常抓包不作为正常科学帧或 CRC 验收证据。

```text
EB 90 | 55 | AA | 01 07 | AA | UTC_seconds_u32 | microseconds_u32 |
data[252] | crc16_be
```

| Offset | 字段 | 说明 |
| --- | --- | --- |
| 0–1 | 同步头 | `EB 90` |
| 2 | 发送地址 | `55`（等离子探针） |
| 3 | 接收地址 | `AA`（测控数传一体机） |
| 4–5 | 数据长度 | `0107` |
| 6 | 数据类型 | `AA`，科学数据固定填充 |
| 7–10 | UTC 时间戳 | 秒级 `u32`，大端 |
| 11–14 | 微秒偏移 | `u32`，大端，必须小于 1,000,000；与 UTC 共同标识两个通道首点时间 |
| 15–266 | 数据域 | `DATA0..DATA251` |
| 267–268 | 校验码 | `u16`，大端；有效数据的 CRC16 |

## 数据域解码

- `DATA0..1`：通道 1 第 1 点，`u16` 大端绝对值。
- `DATA2..3`：通道 2 第 1 点，`u16` 大端绝对值。
- `DATA4, DATA6, …, DATA250`：通道 1 后续点相对前一点的有符号 8 位差分值。
- `DATA5, DATA7, …, DATA251`：通道 2 后续点相对前一点的有符号 8 位差分值。
- 每帧从各通道首个绝对值重新恢复，越出 `0..=65535` 时拒收，不跨帧累加。
- `i8` 补码解释沿用现有实现；厂家负差值编码仍待确认。
- 两通道均有 125 个采样点；10K 采样率经 4 选 1 抽取为 2500 samples/s，对应间隔 400 μs、每帧 50 ms。
- 图表暂用 `(ADC - 32768) / 6.4` 估算 mV，厂家校准尚未确认；原始 ADC 含义不变。

## 长度与校验约定

本项目统一采用以下规则：

- 经 UDP 重组后的单帧 LVDS 原始数据长度为 `269 B`；
- 校验码为帧尾 `2 B`，按大端读取，严格覆盖 `frame[7..267]` 共 260B：UTC 4B + 微秒 4B + DATA 252B，不含 TYPE 和 CRC；
- `0x0107 = 263`，表示从数据类型到 CRC16 末尾的 263 字节；UDP 分片头中的 `frame_len` 是当前网口数据的帧边界；
- LVDS 原始帧内没有包序号字段；UDP `frame_seq` 是独立的 `u32`。桌面当前截为 `u16` 传入既有科学存储，完整序号保留列为后续任务。

CRC16 使用现有 CRC16-CCITT-FALSE：多项式 `0x1021`、初值 `0xFFFF`、不反射、最终异或 `0x0000`，与厂家 `Calculate_CRC16` 的逐位算法一致。标准向量为空输入 `FFFF`、ASCII `123456789` → `29B1`。

覆盖起点、独占终点、CRC 字段偏移分别集中为 `LVDS_CRC_CALC_START=7`、`LVDS_CRC_CALC_END=267`、`LVDS_CRC_FIELD_OFFSET=267`。该 260B 范围是新版“有效数据”的工作解释（`SPEC_ASSUMPTION`）；厂家 C 函数仅证明算法，实际调用的 `data` 指针和 `length` 仍待确认。

当前所有正式入口均强制检查结构 → CRC → 时间 → ADC，再输出 `ScientificFrame`。不匹配返回 `ChecksumMismatch { expected, actual }`，不回退其他范围，不进入科学缓存、存储或图表。桌面按 500ms 聚合错误日志并保留最近计算/接收 CRC。独立人工黄金帧和验证状态见 [CRC16 实施报告](LVDS_CRC16_IMPLEMENTATION_REPORT.md)，不代表真实硬件已通过验收。
