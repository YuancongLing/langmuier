# 等离子体探针载荷数据格式及编排要求（2026-07-24）

> 来源：`数据格式及编排要求-等离子体探针-20260724（公开）.docx`。
> 本文为便于软件实现和审查而转写的 Markdown；原始 `.docx` 仍是归档依据。

## 接口与节奏

- 接口：LVDS；1 位时钟、1 位数据、1 位门控。
- 每 50 ms 一帧，即每秒 20 帧。
- CLK：11.11 MHz、占空比 45%–55%、仅在传输期间有效。
- FLAG：低电平有效，代表帧有效/允许发送。
- DAT：FLAG 下降后发送，FLAG 保持低电平直至一帧结束。
- 多字节字段高字节先输出；字节内高位先输出。

## 科学数据帧

当前网口交付的 LVDS 原始帧固定为 **269 字节**，末尾校验码为 **2 字节 CRC16（高字节在前）**。该长度以 UDP 分片头的 `frame_len = 0x0000010D` 和实测的 293 字节 UDP 数据报（24 字节分片头 + 269 字节 LVDS 原始帧）为准。实包重组后的数据以 `EB 90` 开头。

```text
EB 90 | 55 | AA | 01 07 | AA | UTC_seconds_u32 | microseconds_u32 |
data[252] | crc16_be
```

| 字段 | 说明 |
| --- | --- |
| 同步头 | `EB 90` |
| 发送地址 | `55`（等离子探针） |
| 接收地址 | `AA`（测控数传一体机） |
| 数据长度 | `0107` |
| 数据类型 | `AA`，科学数据固定填充 |
| UTC 时间戳 | 秒级 `u32`，大端 |
| 微秒偏移 | `u32`，大端；与 UTC 时间戳共同标识两个通道首采样点时间 |
| 数据域 | `DATA0..DATA251` |
| 校验码 | `u16`，大端；有效数据的 CRC16 |

## 数据域解码

- `DATA0..1`：通道 1 第 1 点，`u16` 大端绝对值。
- `DATA2..3`：通道 2 第 1 点，`u16` 大端绝对值。
- `DATA4, DATA6, …, DATA250`：通道 1 后续点相对前一点的有符号 8 位差分值。
- `DATA5, DATA7, …, DATA251`：通道 2 后续点相对前一点的有符号 8 位差分值。
- 两通道均有 125 个采样点；采样间隔由 50 ms / 125 推得为 400 μs。

## 长度与校验约定

本项目统一采用以下规则：

- 经 UDP 重组后的单帧 LVDS 原始数据长度为 `269 B`；
- 校验码为帧尾 `2 B`，按大端读取，覆盖校验码之前的有效数据；
- `0x0107 = 263`，表示从数据类型到 CRC16 末尾的 263 字节；UDP 分片头中的 `frame_len` 是当前网口数据的帧边界；
- UDP 分片头的 `frame_seq` 用作采集文件的帧序号；LVDS 原始帧内没有包序号字段。

CRC16 参数已由下位机最终确认：多项式 `0x1021`、初值 `0xFFFF`、不反射、最终异或为 `0x0000`，即 `Calculate_CRC16` 的逐位实现。按文档“有效数据”范围复算时，当前实包尾部 CRC 尚不匹配，因此接收端先解析并保留该字段；取得下位机调用 `Calculate_CRC16(data, length)` 的 `data` 起点和 `length` 后再启用实时拒收。
