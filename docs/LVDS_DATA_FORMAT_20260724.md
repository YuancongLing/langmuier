# 等离子体探针载荷数据格式及编排要求（2026-07-24）

> 来源：`数据格式及编排要求-等离子体探针-20260724（公开）.docx`。
> 本文为便于软件实现和审查而转写的 Markdown；原始 `.docx` 仍是归档依据。

## 接口与节奏

- 接口：LVDS；1 位时钟、1 位数据、1 位门控。
- 每 50 ms 一帧，即每秒 20 帧。
- CLK：11.11 MHz、占空比 45%–55%、仅在传输期间有效。
- FLAG：低电平有效，代表帧有效/允许发送。
- DAT：FLAG 下降后发送，FLAG 保持低电平直至一帧结束。
- 多字节字段高字节先输出；字节内高位先输出。

## 科学数据帧

字段表给出一字节校验和，且长度字段为 `0107`（263），因此可自洽的实现帧长为 **270 字节**：

```text
EB 90 | 55 | AA | 01 07 | AA | UTC_seconds_u32 | microseconds_u32 |
sequence_u16 | data[252] | sum8
```

| 帧偏移 | 字段 | 说明 |
| ---: | --- | --- |
| 0..1 | 同步头 | `EB 90` |
| 2 | 发送地址 | `55`（等离子探针） |
| 3 | 接收地址 | `AA`（测控数传一体机） |
| 4..5 | 数据长度 | `0107`；数值上对应类型至 `DATA251` 的 263 字节，校验和位于长度字段之外 |
| 6 | 数据类型 | `AA`，科学数据固定填充 |
| 7..10 | UTC 时间戳 | 秒级 `u32`，大端 |
| 11..14 | 微秒偏移 | `u32`，大端；与 UTC 时间戳共同标识两个通道首采样点时间 |
| 15..16 | 包序号 | `u16`，大端 |
| 17..268 | 数据域 | `DATA0..DATA251` |
| 269 | 校验和 | 有效数据累加和低 8 位 |

## 数据域解码

- `DATA0..1`：通道 1 第 1 点，`u16` 大端绝对值。
- `DATA2..3`：通道 2 第 1 点，`u16` 大端绝对值。
- `DATA4, DATA6, …, DATA250`：通道 1 后续点相对前一点的有符号 8 位差分值。
- `DATA5, DATA7, …, DATA251`：通道 2 后续点相对前一点的有符号 8 位差分值。
- 两通道均有 125 个采样点；采样间隔由 50 ms / 125 推得为 400 μs。

## 文档内部歧义

前文文字称“269 字节”“校验码为 2 字节”；字段表则称“检验码（1 字节）”，并给出 `0107`。字段表对长度含义的文字也写有“数据类型 + 数据域 + 校验和”，但若把最后一字节校验和计入则总数会是 `0108`。

上位机采用唯一可自洽的解释：长度 `0107` 覆盖从数据类型到 `DATA251` 的 263 字节，末尾一字节累加和不计入长度。因此总帧长度为 `6 + 263 + 1 = 270` 字节。这与字段偏移、采样域 252 字节、单字节校验和均一致。
