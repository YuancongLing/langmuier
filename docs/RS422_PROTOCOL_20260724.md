# 星务与等离子体密度探针单机 RS422 串行通信协议（2026-07-24）

> 来源：`星务与等离子体密度探针单机RS422串行通信协议-20260724（公开）.doc`。
> 本文为便于软件实现和审查而转写的 Markdown；原始 `.doc` 仍是归档依据。

## 物理层

- 接口：RS422，点对点、异步、差分全双工。
- 波特率：115200 bps。
- 每字节：1 起始位、8 数据位（低位先传）、1 奇校验位、1 停止位，即 **8O1**。
- 硬件流控：无。
- 多字节字段：高字节在前；帧内连续发送。
- 遥测请求响应时间：不大于 2 ms；帧间隔不小于 1 μs。
- 探针连续 20 秒未收到轮询指令时，重新配置自身物理串行接口。

## 通用帧格式

```text
EB 90 | sender | receiver | length_be_u16 | type | data[1..1016] | sum8(type + data)
```

`length_be_u16` 的含义为：`type + data + checksum` 的字节数。

## 上行：星务计算机 → 等离子体密度探针

发送地址为 `F0`，接收地址为 `55`，数据长度固定为 `0006`。

### 遥测请求（12 字节）

```text
EB 90 F0 55 00 06 11 9B 9B 9B 9B 7D
```

`7D = SUM8(11 9B 9B 9B 9B)`。

### 控制指令（12 字节）

```text
EB 90 F0 55 00 06 | type | data1 | data2 | data3 | data4 | sum8
```

| 功能 | type | data1 | data2 | data3 | data4 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 三角波模式 | `21` | `55` | 扫描频率 `00..64` | `9B` | `9B` |
| 正弦波模式 | `21` | `AA` | 扫描频率 `00..64` | `9B` | `9B` |
| 直流 DC 模式 | `21` | `BB` | 电压高字节 | 电压低字节 | `9B` |
| LVDS 发送使能 | `31` | `55` | `9B` | `9B` | `9B` |
| LVDS 发送失能 | `31` | `AA` | `9B` | `9B` | `9B` |

原始 `.doc` 的表 2-4 使用合并单元格：`0x21` 纵向覆盖三角波、正弦波和 DC 三行，`0x31` 纵向覆盖 LVDS 使能和失能两行。因此 `0xAA` 与 `0xBB` 是各自控制指令的 `data1` 模式选择值，不是数据类型。电压下发字段按原始值使用大端序；表 2-4 未定义独立的下发电压范围，不能把遥测返回字段的 `0000..1388` 直接当作已硬件验证的下发限制。

六条核对帧如下：

```text
telemetry       EB 90 F0 55 00 06 11 9B 9B 9B 9B 7D
triangle 50     EB 90 F0 55 00 06 21 55 32 9B 9B DE
sine 50         EB 90 F0 55 00 06 21 AA 32 9B 9B 33
DC 1000         EB 90 F0 55 00 06 21 BB 03 E8 9B 62
LVDS on         EB 90 F0 55 00 06 31 55 9B 9B 9B 57
LVDS off        EB 90 F0 55 00 06 31 AA 9B 9B 9B AC
```

## 下行：等离子体密度探针 → 星务计算机

探针仅对遥测请求应答；控制指令没有独立应答帧。

### 遥测应答（34 字节）

```text
EB 90 55 F0 00 1C 1A | data1..data26 | sum8
```

| 帧偏移 | 字段 | 编码 / 说明 |
| ---: | --- | --- |
| 0..1 | 同步头 | `EB 90` |
| 2 | 发送地址 | `55`（探针） |
| 3 | 接收地址 | `F0`（星务） |
| 4..5 | 数据长度 | `001C`，包括类型、26 字节数据域和校验和 |
| 6 | 数据类型 | `1A`（遥测应答） |
| 7 | data1 | 遥测指令计数 |
| 8 | data2 | 正确指令计数 |
| 9 | data3 | 错误指令计数 |
| 10..13 | data4..7 | 当前绝对时间，秒级 `u32`，大端 |
| 14..17 | data8..11 | 当前自守时时间，秒级 `u32`，大端 |
| 18 | data12 | 当前工作模式：`55` / `AA` / `BB` |
| 19 | data13 | 扫描频率：`01..64` |
| 20..21 | data14..15 | 扫描电压：`u16` 大端，`0000..1388` |
| 22 | data16 | CPU 温度 |
| 23 | data17 | AD9833 状态 |
| 24 | data18 | DAC8563 状态 |
| 25 | data19 | 第一路 ADC 芯片工作状态 |
| 26 | data20 | 第二路 ADC 芯片工作状态 |
| 27 | data21 | 当前 LVDS 发送状态 |
| 28..32 | data22..26 | 上一条接收到的注入指令内容；不包含遥测请求 |
| 33 | 校验和 | `SUM8(type + data1..data26)` |

该协议没有“DDS2”“辅助状态”“PCB 温度”或“三轴磁场”字段。AD9833 状态是唯一的 DDS 类状态。
